# Vinheria Agnello - Checkpoint 02

## Descrição do Projeto
Este projeto consiste num Sistema de Avaliação de Estoque e Tendência de Vinhos. Foi desenvolvido aplicando os fundamentos de JavaScript: uso de funções reutilizáveis, gestão de escopo de variáveis e laços de iteração, garantindo o registo em sequência sem a utilização de arrays ou objetos, conforme os requisitos.
